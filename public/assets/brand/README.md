# WXP Electronics branding

These assets reproduce the user-supplied official WXP ELECTRONICS SDN BHD
reference and were visually checked against the branding on pages 1, 4, 10
and 13 of the supplied EVMobii brochure.

- `wxp-electronics-emblem.svg`: compact emblem, original aspect ratio.
- `wxp-electronics-logo-navy.svg`: horizontal arrangement for light surfaces.
- `wxp-electronics-logo-white.svg`: the same outlines with white lettering.
- PNG icons: square exports of the compact emblem for browser and Apple icons.

All lettering, including 万 and 宝, is outlined. The central mechanical shape,
stylized W/P lettering and four diagonal elements follow the supplied raster;
the lower-right element is red in both authoritative references. No green
element is clearly resolved in those references.

The provided screenshot contains a 176 × 194 px emblem and a 432 × 67 px
wordmark. The brochure contains flattened 961 × 1417 px page images and a
smaller logo. These are source-traced vector reproductions, not recovered
original vector artwork. Subpixel geometry and exact production spot colors
cannot be certified from these raster references. Replace with an official
AI/EPS/SVG master if one becomes available, retaining the existing dimensions.
